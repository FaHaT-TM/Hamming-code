# Презентация для защиты

**Файл:** `Презентация_защиты.pptx` (16 слайдов, 16:9).

**Просмотр без PowerPoint:** `Презентация_защиты.pdf` — та же презентация в PDF;
`Титульный_слайд.png` — изображение титульного слайда.

**Структура:**

1. Титульный слайд.
2. Актуальность и цель.
3. Задачи.
4. Код Хэмминга (7,4) — с рисунком исправления ошибки.
5. Свёрточный код и алгоритм Витерби — с диаграммой состояний.
6. Модель системы связи — со схемой канала.
7. План эксперимента.
8. Зависимости BER от Eb/N0 — сравнительный график.
9. Энергетический выигрыш при BER = 10⁻⁴ — график окрестности 10⁻⁴.
10. Почему свёрточный код выигрывает больше.
11. Честность статистики (про недостижимость ≥100 ошибок при 8–10 дБ) и ограничения.
12. Выводы.
13–15. Возможные вопросы преподавателя в формате «вопрос — ответ» (реализация; эксперимент и статистика; результаты). Полная версия — `документы/Вопросы_к_защите.md`.
16. Заключительный слайд.

Все числа на слайдах соответствуют notebook и отчёту (`документы/отчёты/Отчёт_по_результатам.md`):
выигрыш при BER = 10⁻⁴ — свёрточный код +1.4 дБ, код Хэмминга +0.3 дБ
(уточняющая сетка 0.2 дБ: +1.39 [+1.34; +1.43] и +0.32 [+0.29; +0.34] дБ).

**Перегенерация** (нужен необязательный пакет `python-pptx`, в основной
`requirements.txt` не входит):

```bash
pip install python-pptx
python scripts/make_presentation.py
```

Рисунки берутся из `results/figures/*.png`; при их обновлении презентацию
следует перегенерировать.
