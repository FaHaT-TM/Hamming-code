# Презентация для защиты

**Файл:** `Презентация_защиты.pptx` (16 слайдов, 16:9).

**Если PowerPoint нет:** `Презентация_защиты.pdf` — та же презентация в PDF,
а `Титульный_слайд.png` — картинка титульного слайда.

**Что на слайдах:**

1. Титульный слайд.
2. Актуальность и цель.
3. Задачи.
4. Код Хэмминга (7,4) — с рисунком исправления ошибки.
5. Свёрточный код и алгоритм Витерби — с диаграммой состояний.
6. Модель системы связи — со схемой канала.
7. План эксперимента.
8. Зависимости BER от Eb/N0 — сравнительный график.
9. Энергетический выигрыш при BER = 10⁻⁴ — график окрестности 10⁻⁴.
10. Почему свёрточный код выигрывает больше.
11. Честность статистики (про недостижимость ≥100 ошибок при 8–10 дБ) и ограничения.
12. Выводы.
13–15. Возможные вопросы в формате «вопрос — ответ» (реализация; эксперимент и статистика; результаты). Полная версия — `документы/Вопросы_к_защите.md`.
16. Заключительный слайд.

Все числа на слайдах те же, что в notebook и в отчёте
(`документы/отчёты/Отчёт_по_результатам.md`): выигрыш при BER = 10⁻⁴ — свёрточный код
+1.4 дБ, код Хэмминга +0.3 дБ (уточняющая сетка 0.2 дБ: +1.39 [+1.34; +1.43] и
+0.32 [+0.29; +0.34] дБ).

**Как перегенерировать** (нужен необязательный пакет `python-pptx`, в основной
`requirements.txt` его нет):

```bash
pip install python-pptx
python scripts/make_presentation.py
```

Рисунки берутся из `results/figures/*.png`. Если их обновлять, презентацию нужно
перегенерировать, иначе картинки в ней останутся старыми.

**Про состояние файлов.** Скрипт `make_presentation.py` собирает только .pptx, а PDF и
PNG из него делает LibreOffice. Сами файлы `Презентация_защиты.pptx`,
`Презентация_защиты.pdf` и `Титульный_слайд.png` собраны 2026-10-24 и не
перерегенерированы, поэтому их байты прежние.

2026-10-29 в генераторе поправлены заголовки слайдов 13–15 — теперь это
«Вопросы и ответы: реализация», «Вопросы и ответы: эксперимент и статистика»,
«Вопросы и ответы: результаты». В файлах презентации заголовки остались прежними,
потому что файлы не пересобирали. Чтобы привести их в соответствие с генератором,
нужно выполнить `python scripts/make_presentation.py`, а затем пересохранить из
полученного .pptx файлы PDF и PNG в LibreOffice. Содержание слайдов (вопросы, ответы
и все числа) не менялось.
