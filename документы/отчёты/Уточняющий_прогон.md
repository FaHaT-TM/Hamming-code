# Уточняющий прогон (шаг 0.2 дБ): результаты

Это локальное уточнение окрестности BER = 10⁻⁴, набор данных отдельный.

Протокол зафиксирован до запуска (§4 спецификации): объёмы заданы заранее, остановки по числу ошибок нет. С прежними прогонами результаты **не объединяются** — основной оценкой остаётся то, что посчитано по своим наборам.

* seed уточнения: **20261026** (ранее не использовался);
* объёмы: без кода и Хэмминг по 30,000,000 информационных бит на точку, Витерби — 1000 пакетов по 10000 (10,000,000 бит);
* bootstrap: 10000 реплик, отдельный seed **777001**;
* потоки: `SeedSequence(entropy=[seed, scheme_tag, scheme_id, chunk_index, purpose])`, purpose = 1 (биты) / 2 (шум); перезапуска одним seed на каждом пакете нет.

|---|---:|---:|---:|---:|---:|
| BPSK без кодирования | 8.3983 | 8.3724 | -0.0259 | 8.3982 | -0.00004 |
| Хэмминг (7,4) | 8.0841 | 8.0761 | -0.0080 | 8.0831 | -0.00105 |

Это характеристика **процедуры интерполяции**, а не экспериментальная оценка: на гладких теоретических кривых сетка 1 дБ даёт смещение порядка сотых долей дБ, а сетка 0.2 дБ — на порядки меньше. Это отдельный источник: с bootstrap-интервалом он не складывается.
