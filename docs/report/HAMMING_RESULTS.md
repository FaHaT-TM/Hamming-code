## 7. Минимальное кодовое расстояние
- Полный перебор попарных расстояний (16×16): **d_min = 3**
- Минимальный вес ненулевого кодового слова: **3**
- Граница Синглтона d_min ≤ n − k + 1 = 7 − 4 + 1 = 4: выполнена (**True**); для совершенного кода Хэмминга d_min = 3 < 4
- Граница Хэмминга: 2^n / (1 + n) = 16.00 ≥ 2^k = 16 — код совершенный
- Гарантированно исправляемых ошибок: t = ⌊(d_min−1)/2⌋ = **1**
- Ранг G (над GF(2)): **4**; ранг H: **3**

### Совершенность кода и отсутствие исхода «отказ»
Шары радиуса 1 покрывают всё пространство: 2^k·(1 + n) = 16·(1 + 7) = 128 = 2^n = 128. Следовательно, каждому принятому 7-битному слову соответствует единственное кодовое слово на расстоянии ≤ 1: у декодера **нет исхода «отказ»**, и фактическое число ошибок канала он не определяет. Термин bounded-distance применяется с оговоркой: радиус t = 1, отказов нет.

## 9. Ограничение: две ошибки (ожидаемое поведение, не дефект)
- Исходное слово: `0110011` (u = `1011`)
- Инверсия позиций 1 и 2: `1010011`
- Синдром: (1, 1, 0), j = 3 (ложная позиция)
- После «коррекции»: `1000011`
- Извлечённая информация: `0011` вместо `1011` — **декодер выдал неверную информацию без признака отказа**
- Синдром исправленного слова: (0, 0, 0) — повторная проверка не подтверждает правильность
**Формулировка для отчёта:** двойная ошибка вызвала ненулевой синдром, то есть нарушение кодовых проверок *обнаружено*, но число ошибок не распознано: двойная ошибка ошибочно интерпретирована как одиночная. После ошибочной коррекции декодер выдал неверную информацию **без признака отказа**; полученное слово снова принадлежит коду (синдром нулевой), поэтому повторная проверка синдрома правильность не подтверждает.
Код (7,4) с d_min = 3 гарантированно исправляет одну ошибку на слово. Одновременное «исправить одну и обнаружить две» для данной схемы не заявляется.
