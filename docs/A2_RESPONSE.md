## 2. Главные числа (обновлённые)

**Расширенный объём, BER = 10⁻⁴, $L$ = 10⁴:**

| Схема | Точечная оценка | Bootstrap 95 % (кластерный) | SD bootstrap | Чувствительность к способу интерполяции |
|---|---|---|---|---|
| Хэмминг (7,4) | **+0.27 дБ** | [+0.24; +0.30] | 0.02 дБ | +0.10 дБ |
| свёрточный (7,5)₈ + Витерби | **+1.39 дБ** | [+1.34; +1.45] | 0.03 дБ | +0.19 дБ |

Три источника неопределённости разделены явно:

1. **статистическая** — bootstrap по независимым единицам (узкая);
2. **интерполяционная** — разница между $\lg$-интерполяцией и линейной по BER: 0.10 и 0.19 дБ;
3. **редкие события** — для $K<30$ никакая нормальная аппроксимация не применяется,
   приводится только консервативная граница по независимым единицам.

Для Хэмминга (2) сопоставима с самим эффектом (0.10 против 0.27 дБ) — это прямо оговорено
в отчёте и в notebook.

## 3. Кластерные интервалы: что они дали

Пример (расширенный объём, 8 дБ, Хэмминг): $E=2442$, $M=5\,000\,000$, $K=1424$,
$\overline W = 1.221\cdot10^{-4}$, $SE = 3.5\cdot10^{-6}$,
кластерный 95 % $[1.15\cdot10^{-4}; 1.29\cdot10^{-4}]$ против консервативного
$[6.8\cdot10^{-5}; 3.0\cdot10^{-4}]$. Для Витерби при 7 дБ (расширенный прогон)
$K \approx 700$, кластерный интервал также информативен; при 9–10 дБ — нет.

Консервативные интервалы **сохранены как отдельный вид оценки**, как и требовалось:
они не требуют нормальной аппроксимации, но для Витерби при малом $M$ неинформативны
(это ограничение метода $q/\ell \le P_b \le q$, а не свойство кодера).

## §2. Несоответствие K при 7 дБ (свёрточный, extended)

**Причина найдена: ошибка текста, не данных.** В `ber_results_extended.csv` для точки
conv 7 дБ: `M = 1000` пакетов, `E = 949` ошибок, `K = 405` пакетов с ошибками,
`Σz² = 3117`. Значение «≈700», попавшее в предыдущий ответ, было опечаткой: 700 — это
не число пакетов с ошибками. Данные не переписывались, пересчёта не потребовалось.

Чтобы такое не повторялось, добавлен `scripts/check_histograms.py`: для **каждой** строки
всех трёх CSV проверяются 4 тождества

1. `Σ_j h_j = M` (число независимых единиц),
2. `Σ_j j·h_j = E` (число ошибок),
3. `M − h_0 = K` (единицы с ошибками),
4. `Σ_j j²·h_j = ΣZ²`.

Результат: **81 строка (main + extended + refinement), 0 расхождений**
(`results/data/histogram_checks.json`, `docs/report/HISTOGRAM_CHECKS.md`).
Контрольная строка conv 7 дБ extended: M=1000, E=949, **K=405**, Σz²=3117 — совпадает.

Отдельно: интервал стандартной ошибки не требует гистограмм — для кластерной SE достаточно
`M`, `E`, `ℓ`, `ΣZ²`; гистограммы используются только для проверки согласованности
и для точного кластерного распределения.

## §5. Bootstrap: 10 000 реплик и диагностика

`bootstrap_gain` переработан по §5 заключения:

* ресэмплируются **все** схемы (а не только сравниваемая пара);
* пересечение с уровнем ищется по **всей** сетке, а не по заранее выбранной паре
  (иначе при малом числе точек оценка смещена);
* сохраняются `n_valid`, `invalid_fraction`, `pair_changed_fraction`, `method`, `note`;
* невалидные реплики **не отбрасываются молча**: их число и доля выводятся в CSV, отчёте
  (§7.1) и notebook; скрытой экстраполяции или отсечения нет;
* seed bootstrap — **777001**, независимый от seed эксперимента; 10 000 реплик.

Результат при BER = 10⁻⁴:

| Набор | Хэмминг | Свёрточный | невалидных | смена пары точек |
|---|---|---|---|---|
| refinement 0.2 дБ | +0.32 [+0.29; +0.34] | +1.39 [+1.34; +1.43] | 0 % | 0 % / 17.0 % |
| extended 1 дБ | +0.27 [+0.24; +0.30] | +1.39 [+1.34; +1.45] | 0 % | 0 % / 13.7 % |

Смена пары у свёрточного кода в 14–17 % реплик — прямое подтверждение того, что поиск
пересечения обязан идти по всей сетке; при фиксированной паре такие реплики дали бы
смещённую или отсутствующую оценку.

## §6. Терминология и сеточная ошибка

1. Числа 0.10 и 0.19 дБ называются **разницей между способами интерполяции**, а не
   погрешностью; с bootstrap-интервалом они не складываются.
2. Добавлены `theory_crossing_exact` / `theory_crossing_grid` / `grid_error_report`
   (точный корень — бисекция по точной теории). Сеточная ошибка процедуры на уровне 10⁻⁴:

| Кривая | Точный корень, дБ | Сетка 1 дБ | Сетка 0.2 дБ |
|---|---:|---:|---:|
| BPSK | 8.3983 | 8.3724 (−0.0259) | 8.3982 (−3.8·10⁻⁵) |
| Хэмминг (7,4) | 8.0841 | 8.0761 (−0.0080) | 8.0831 (−0.0010) |

3. Кластерный интервал при `K ≥ 30` по-прежнему обозначен как **отдельный приближённый
   вид оценки**; консервативные интервалы сохранены в CSV и в таблицах.

## §7. Витерби

Без изменений в алгоритме: 504 случая (L=1…6) сверены с полным перебором — 0 несовпадений
метрики, 463 единственных оптимума с 0 несовпадений сообщения, 41 неоднозначный случай,

исследовании**; утверждения о его невлиянии на BER не делаются.
